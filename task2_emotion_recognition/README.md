# Task 2 - Emotion Recognition from Speech

CodeAlpha Machine Learning Internship - Task 2

This project uses the RAVDESS speech dataset and MFCC features to recognize emotions from speech audio using a Convolutional Neural Network (CNN).

## Model
- CNN
- MFCC Features
- 8 Emotion Classes

## Outputs
- Confusion Matrix
- Accuracy Curve
- Loss Curve
- Trained CNN Model
